**Goal:** Fix every P1/P2 bug found by the real-world QA run (`/home/om/Karma/camoufox-qa/FINDINGS.md` #1–#9), and also #10 (iframe/shadow scoping), in the camoufox-rs library and CLI.

**Architecture:**
- Close/shutdown gets a writer-EOF close, a closer handle kept outside the instance mutex, and a daemon shutdown coordinator.
- Each page gets three trackers:
  - a generation-aware execution-context tracker;
  - a dialog tracker that can reject in-flight requests on its session;
  - (later) a context-level page-target registry that adopts popups and child frames.
- The CLI adds a download log, the `dialog`/`downloads` commands, and the `--bypass-csp`, `--downloads-dir`, `--dialogs` and `--frame` flags.

**Tech Stack:** Rust 2021 (MSRV 1.85), std threads and channels, serde/serde_json, clap (feature `cli`), Juggler protocol over pipes (see `docs/PROTOCOL.md`), Camoufox 158.

- [ ] **Step 3: Implement `ExecContextTracker`**

```rust
//! Main-world execution-context tracking for one frame.
//!
//!   created(x) ──► live += x, current = x
//!   destroyed(x) ─► live -= x, current = None if current == x
//!   begin_navigation ─► token{prev: current}, current = None
//!   abort_navigation(token) ─► if current is None && prev ∈ live: current = prev
use std::collections::HashSet;
use std::sync::Mutex;

#[derive(Debug, Default)]
struct State { current: Option<String>, live: HashSet<String> }

#[derive(Debug, Default)]
pub(crate) struct ExecContextTracker { state: Mutex<State> }

#[derive(Debug, Clone)]
pub(crate) struct NavToken { prev: Option<String> }

impl ExecContextTracker {
    pub(crate) fn new() -> Self { Self::default() }
    fn lock(&self) -> std::sync::MutexGuard<'_, State> {
        self.state.lock().unwrap_or_else(std::sync::PoisonError::into_inner)
    }
    pub(crate) fn current(&self) -> Option<String> { self.lock().current.clone() }
    pub(crate) fn on_created(&self, ctx_id: String) {
        let mut s = self.lock();
        s.live.insert(ctx_id.clone());
        s.current = Some(ctx_id);
    }
    pub(crate) fn on_destroyed(&self, ctx_id: &str) {
        let mut s = self.lock();
        s.live.remove(ctx_id);
        if s.current.as_deref() == Some(ctx_id) { s.current = None; }
    }
    pub(crate) fn begin_navigation(&self) -> NavToken {
        let mut s = self.lock();
        NavToken { prev: s.current.take() }
    }
    pub(crate) fn abort_navigation(&self, token: NavToken) {
        let mut s = self.lock();
        if s.current.is_none() {
            if let Some(prev) = token.prev {
                if s.live.contains(&prev) { s.current = Some(prev); }
            }
        }
    }
    pub(crate) fn invalidate(&self, ctx_id: &str) {
        let mut s = self.lock();
        if s.current.as_deref() == Some(ctx_id) { s.current = None; }
    }
}
```

pub fn js_query(sel: &str) -> String {
    let parts: Vec<String> = sel.split(">>>").map(|p| serde_json::to_string(p.trim()).unwrap()).collect();
    format!(
        "(() => {{ const parts = [{}]; let root = document; let el = null; \
           for (let i = 0; i < parts.length; i++) {{ \
             el = root.querySelector(parts[i]); if (!el) return null; \
